# PRD: Модульный веб/десктоп клиент Echolet с архитектурой скинов WinAmp (12 скинов)

## 1. Overview (Обзор)
Echolet Web — это веб- и локальный клиент для безопасного обмена сообщениями на базе криптографического ядра Signal Protocol (Double Ratchet E2EE). Данный документ регламентирует архитектуру модульного каркаса в стиле WinAmp (Chassis & Slots) и интеграцию 12 полноценных стилистических тем (скинов) — от ламповых радиол 1950-х и компьютеров 1980-х до скандинавского минимализма (Teenage Engineering OP-1) и кинематографического Sci-Fi (The Matrix, Blade Runner 2049, Interstellar) с мгновенным переключением без потери сессии.

## 2. Context (Контекст)
- **Product:** Echolet (Secure Decentralized Radio Messenger)
- **Module:** `apps/web` (@echolet/web)
- **User Role:** Радиолюбители, операторы защищенной связи, энтузиасты приватности, ценители аутентичного промышленного дизайна
- **Tech Stack:** React 19, TypeScript 5.8, Node.js 22.13 (ESM Companion Server), esbuild, Server-Sent Events (SSE), Tailwind / Custom CSS Modules, Canvas / SVG

## 3. Problem Statement (Проблема)
Традиционные TUI-интерфейсы и базовые монотонные веб-мессенджеры либо неудобны для повседневной работы (проблемы с раскладками клавиатуры, отсутствие мыши), либо лишены индивидуальности и не передают уникальную атмосферу радиосвязи, киберпанка и аналоговой криптографии. Попытки создавать разные интерфейсы «с нуля» приводят к дублированию логики, багам криптографического протокола и раздуванию кодовой базы.

## 4. Goals (Цели)
- **G-1:** Реализовать строгую модульную архитектуру каркаса (WinAmp Semantic Chassis), где геометрия слотов зафиксирована, а скины управляют материалами, шейдерами, индикаторами и типографикой.
- **G-2:** Интегрировать 12 завершенных стилей: 
  1. *Split-Horizon (Tactical HUD)*
  2. *Винтажная Радиола 1950-х (Telefunken/Ригонда)*
  3. *Военный радиоузел Р-250 «Кит»*
  4. *Ламповый осциллограф ЭЛТ*
  5. *Викторианский стимпанк-телеграф*
  6. *Hi-Fi ламповый усилитель (McIntosh/Luxman)*
  7. *Nordic Minimalist (Teenage Engineering OP-1)*
  8. *Ретро-ПК System-84 (1980s IBM/Macintosh era)*
  9. *Nothing Glyph / Dot-Matrix Minimal*
  10. *Cyberpunk 2077 Arasaka HUD*
  11. *The Matrix 1999 (Nebuchadnezzar Operator)*
  12. *Aerospace Glassmorphic Mesh (Sci-Fi 2010s)*
- **G-3:** Обеспечить мгновенное переключение тем на лету (0ms реконнект) с сохранением текущего набора текста, открытого чата и истории телеметрии.

## 5. Non-Goals (Что не входит в рамки)
- Прямое использование чужих товарных знаков, логотипов Apple, IBM, McIntosh, Warner Bros (стилизация должна быть собирательной и юридически безопасной).
- Переписывание криптографического движка Signal Protocol (ядро исполняется в локальном Node.js процессе, браузер — презентационный слой).
- Произвольное перетаскивание окон пользователем (drag-and-drop floating windows) в первом релизе (сохраняется стабильная 3-колоночная сетка).

## 6. Functional Requirements (Функциональные требования)
- **FR-1 (Slot Architecture):** Каркас обязан разделять экран на 5 семантических слотов: `Slot 1: TopDeck`, `Slot 2: VisDeck`, `Slot 3: ContactTuner`, `Slot 4: MessageStream & Transmit`, `Slot 5: HardwareInspector`.
- **FR-2 (Skin Selector):** В шапке TopDeck размещается доступный контрол выбора активного скина из выпадающего списка 12 вариантов. Выбранный скин сохраняется в `localStorage`.
- **FR-3 (Vis Deck Adaptation):** Слот `VisDeck` динамически меняет рендерер в зависимости от скина:
  - Скины 1, 10: FFT-водопад частот.
  - Скины 2, 6: Стрелочный аналоговый VU/S-метр с физической анимацией стрелки и «магический глаз» 6Е5С.
  - Скин 3: Проекционный оптический визир настройки частоты.
  - Скин 4: Круглый ЭЛТ экран с фигурами Лиссажу (зеленый фосфор).
  - Скин 5: Искровой разрядник и бумажная лента с сургучной печатью.
  - Скин 7: Векторный OLED монохромный спектр (стиль OP-1).
  - Скин 8: Янтарный экран с горизонтальными скан-линиями и мигающим дисководом `[DRIVE A: BUSY]`.
  - Скин 9: Светодиодный Glyph-интерфейс (пульсирующие микро-светодиоды).
  - Скин 11: Падающий зелёный цифровой дождь (Matrix Digital Rain) на HTML5 Canvas.
  - Скин 12: Интерактивный 3D топологический граф узлов ретрансляции.
- **FR-4 (Message Bubble Styling):** Формат карточек сообщений адаптируется: пергамент со штампами (Радиола), армейские радиограммы `[СЕКРЕТНО]` (Р-250), перфолента (Стимпанк), янтарный моноширинный терминал (System-84), скандинавские скругленные плашки (OP-1).
- **FR-5 (Telemetry Integration):** Правая панель аппаратного инспектора отображает актуальные крипто-метрики (PreKey Pool, Ping RTT, Double Ratchet state) в стилистике активного скина.

## 7. Non-Functional Requirements (Нефункциональные требования)
- **NFR-1 (Performance):** Переключение скина не должно превышать 16ms (60 FPS), без перезагрузки веб-страницы.
- **NFR-2 (Zero Data Leakage):** Приватные ключи и сессионные секреты Signal никогда не передаются в открытом виде и не хранятся в LocalStorage.
- **NFR-3 (Responsive Canvas):** Все процедурные визуализаторы (водопад, фигуры Лиссажу, Matrix rain) автоматически адаптируются под ширину экрана и освобождают `requestAnimationFrame` при смене вкладки или скина.

## 8. Constraints (Ограничения)
- Совместимость с Node.js >= 22.13.
- Поддержка браузеров Chrome, Safari, Firefox последних двух версий.
- Изоляция CSS-переменных под атрибутом `[data-theme="..."]`.

## 9. Edge Cases (Крайние случаи)
- **EC-1:** Отсутствие соединения с релеем: стрелочные приборы падают на 0, экраны показывают индикацию «OFFLINE / NO CARRIER».
- **EC-2:** Длинное сообщение: бумажная лента и пергамент корректно переносят строки без горизонтального скролла.
- **EC-3:** Быстрое циклическое переключение скинов: таймеры и анимации Canvas корректно останавливаются (no memory leaks).

## 11. Verification (Верификация)
- **Автоматизированная сборка:** `pnpm web:build` без ошибок TypeScript и esbuild.
- **Функциональный тест:** Проверка переключения всех 12 скинов в работающем браузере на `http://localhost:3001` и `http://localhost:3002`.
- **E2E тест сквозной передачи:** Доставка сообщения с проверкой статуса Double Ratchet в каждом из скинов.
