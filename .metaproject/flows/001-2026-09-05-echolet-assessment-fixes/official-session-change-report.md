# Flow 001 — официальный session runtime

Дата: 2026-09-06. Продолжение исправлений после первой волны; Node reference, не готовый мобильный мессенджер.

## Что изменено

Добавлен `packages/session-node` с официальным `@signalapp/libsignal-client@0.102.0`. Вместо собственной ratchet-логики он использует нативные примитивы и сериализованные записи библиотеки. Удалённая identity должна быть явно подтверждена; неизвестные ключи и неявная замена доверенного ключа отклоняются.

`EncryptedSqliteStore` хранит непрозрачные записи в аутентифицированном зашифрованном snapshot SQLite с отдельно переданным ключом. Транзакция сохраняет продвижение сессии вместе с точным outbox, а при приёме — состояние и inbox. Результат возвращается только после COMMIT. Повторная отправка читает прежние байты. Ошибки callback/COMMIT откатывают запись; операции сериализуются; повреждённая база не сбрасывается в пустую сессию.

Ревью обнаружило коллизию проверки содержимого для одиночных UTF-16 surrogate: разные строки превращались в одинаковые UTF-8 байты при вычислении hash. Исправлено вычислением hash от точного JSON payload, который передаётся шифрованию; добавлен RED/GREEN regression.

## Доказательства

- 17 тестов пакета: 10 session-кейсов и 7 storage-кейсов. Включены trust rejection, ответы, out-of-order/crossed sends, replay/tamper, точный retry, rollback, параллельные записи и фактический SIGKILL процесса до/после commit.
- Независимый reviewer дополнительно выполнил два теста Unicode, мутации входных объектов и конкурентного использования одинакового ID.
- [Ревью SignalClient](signal-client-independent-review.md) и [ревью хранения](storage-review.md) принимают ограниченный Node scope.
- Общие команды, результаты и пропущенные проверки зафиксированы в [итоговой верификации](official-session-verification.md).
- [Отчёт реализации](official-libsignal-report.md), [спецификация до кода](official-session-spec.md), [проверка мобильного wrapper](mobile-libsignal-feasibility.md).

## Что остаётся открытым

T9 не закрывается этим пакетом. Нужны версионированный wire bundle с Kyber, привязка Signal identity к подписанному DeviceRecord, собственный mobile bridge, защищённое хранение ключа, управление prekeys и контактный UX. Текущий relay v1 и мобильное демо не подключены к Node runtime. Node native-типы не являются готовым мобильным API.

Нет проверки двух физических телефонов, background delivery, внешнего аудита или пользовательского пилота. SQLite snapshot не защищает от подмены целого файла старой корректной копией и не предназначен для неограниченного роста истории. Lint в workspace пока не выполняет реальных package-проверок. Upstream libsignal не обещает поддержку внешних приложений; за совместимость pinned-версии отвечает проект.

Flow остаётся `in-progress`; результат этой волны — проверенная основа для следующей интеграции. Ограничение demo-режима сохраняется. Git/remote в рабочей папке отсутствуют; коммитов, PR и публикации не было.
