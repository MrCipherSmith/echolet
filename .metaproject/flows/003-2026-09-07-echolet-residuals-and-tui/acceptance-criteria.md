# Acceptance criteria

- AC1: Every item in the residual inventory is dispositioned by evidence, not by assertion: each is fixed, or re-verified as still open and recorded with the reason it is not being fixed, or shown to be stale and deleted from every document that still asserts it. A disposition table names the evidence for each.
- AC2: No document in the repository states something the tree contradicts. In particular no document says the relay fails to stop cleanly, none says the ack-route count oracle is open, none says AC4 is blocked, and none quotes an e2e result under a label that does not describe what was run.
- AC3: `pnpm --filter @echolet/cli test:e2e` runs every end-to-end test file, or the scripts are renamed so that what each one runs is what its name says. Whichever is chosen, every document quoting an e2e figure quotes it under the corrected name and the corrected count.
- AC4: Configuration that does not bind anything is either made to bind or removed. Specifically the cleanup interval must not be presented to an operator in compose files and env examples while the service it names does nothing, and the relay's background timer must be stoppable and covered by tests.
- AC5: A single malformed record does not deny service to unrelated identities, and a single configuration value cannot silently make a mailbox undeliverable. Both are demonstrated by a test that fails before the fix.
- AC6: The operator console runs one command at a time. While a command is in flight a key that would start another starts none, the operator is told why, and the exit class the console reports is the class the CLI actually returned. Demonstrated against a real driven process, not only the pure layer.
- AC7: The console never hides data without saying so: a truncated pane states that it is truncated and how many rows are not shown, and keeps the rows an operator needs rather than the oldest.
- AC8: Every key the console advertises is visible at the minimum viewport, there is a discoverable key list, and at any viewport no emitted line exceeds the viewport width so the unaudited-prototype notice cannot be pushed out of view.
- AC9: The properties flow 002 established are re-verified unchanged on the final tree: renderFrame stays pure, total, deterministic, escape-free and exactly rows by cols; no key material appears in any frame or child argv; the notice appears on every frame; the trust modal cannot confirm what was never painted; and the full matrix is green with zero data races.
- AC10: No test is weakened, skipped, narrowed or deleted to reach any of the above, and every fix lands after a test that failed for the right reason first, with the ordering provable from the git history.
